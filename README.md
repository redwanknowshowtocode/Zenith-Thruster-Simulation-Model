# Why I built this

I wanted to get into the beginnings of making rockets, but since I live in New York City (and flying model rockets are illegal), I instead wanted to simulate how a thruster would work. Using servos for actuators in order to orbit the thruster itself, I was able to also implement the theory of PID to make sure the rocket is always heading straight, thruster pointing downwards. 

# Features
 
- Propelled by a CRM2413A Brushless Metal Motor Contra-Rotating 1300KV
- Thruster is dependent on two HS-5087MH servos.
